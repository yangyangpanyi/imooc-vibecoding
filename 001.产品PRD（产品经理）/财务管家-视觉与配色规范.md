# 「财务管家」视觉与配色规范

> 版本 v1.0 · 2026-11-21 · 设计基调：**霓虹深色 FinTech**（炫酷、聚焦数字）

---

## 1. 设计定位

- **深色优先**：默认深色主题，高级感强、手机 OLED 屏省电、数字与图表更突出。
- **渐变主色**：紫 → 蓝 → 青，体现「金融科技」的科技感与流动感。
- **霓虹点缀**：关键数字、激活态、主按钮用发光/渐变，制造「炫酷」记忆点。
- **浅色备选**：提供浅色主题，供用户切换或桌面端使用。

---

## 2. 色板总览

### 2.1 品牌主色（渐变）

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--brand-1` | `#6366F1` | 渐变起点（靛蓝） |
| `--brand-2` | `#8B5CF6` | 渐变中点（紫） |
| `--brand-3` | `#06B6D4` | 渐变终点（青） |

主渐变（默认 135°）：

```css
linear-gradient(135deg, #6366F1 0%, #8B5CF6 50%, #06B6D4 100%)
```

### 2.2 霓虹强调

| Token | 色值 | 用途 |
| --- | --- | --- |
| `--neon-cyan` | `#22D3EE` | 激活态、高亮、图表高亮 |
| `--neon-purple` | `#A78BFA` | 次级点缀、hover |

### 2.3 语义色（收支）

| 语义 | Token | 色值 | 说明 |
| --- | --- | --- | --- |
| 收入 / 正向 | `--income` | `#34D399` | 荧光绿，配合 `+` 符号 |
| 支出 / 负向 | `--expense` | `#FB7185` | 珊瑚红，配合 `-` 符号 |
| 警示 / 超支 | `--warning` | `#FBBF24` | 琥珀黄 |

> 规则：颜色不作为唯一信息载体，收支金额同时带 `+`/`-` 符号。

## 3. 深色主题（默认）

```css
:root[data-theme="dark"] {
  /* 背景层 */
  --bg:          #0B1120;   /* 页面背景（深蓝黑） */
  --surface:     #151E33;   /* 卡片表面 */
  --surface-2:   #1C2740;   /* 悬浮层 / 弹层 */
  --border:      #28334D;   /* 边框 / 分隔线 */

  /* 文字 */
  --text-primary:   #E7ECF5;   /* 主文字 */
  --text-secondary: #94A3B8;   /* 次文字 */
  --text-muted:     #64748B;   /* 弱文字 / 占位 */

  /* 品牌与语义（同 2.1 / 2.3） */
}
```

玻璃拟态卡片（表面叠加）：

```css
background: rgba(255, 255, 255, 0.04);
backdrop-filter: blur(12px);
border: 1px solid rgba(255, 255, 255, 0.08);
```

## 5. 图表分类色板（8 色，深色底高饱和可区分）

```css
--c1: #3987e5;  /* 蓝 */
--c2: #d95926;  /* 橙 */
--c3: #199e70;  /* 青绿 */
--c4: #c98500;  /* 黄 */
--c5: #d55181;  /* 品红 */
--c6: #0ca30c;  /* 绿 */
--c7: #9085e9;  /* 紫 */
--c8: #e66767;  /* 红 */
```

经 dataviz 校验器修正：原品牌近色系中蓝 `#60A5FA` 与浅紫 `#A78BFA` 连正常色觉都难区分（ΔE 10.2，低于 15 下限），故图表分类色改用经色盲（CVD）安全验证的深色色板；品牌渐变仅用于 UI 装饰。

使用顺序：按此**固定顺序**取色（顺序即色盲安全机制，不可循环复用、不可生成第 9 色）；相邻色对均通过 CVD ΔE ≥ 8 与正常色觉 ΔE ≥ 15 验证。

## 6. 炫酷实现手法（开发落地）

| 手法 | 应用位置 | 实现要点 |
| --- | --- | --- |
| 渐变填充 | 主按钮、头部背景 | 2.1 主渐变 + 白色文字 |
| 渐变文字 | 余额 / 本月支出等关键数字 | `background: 主渐变; -webkit-background-clip: text; color: transparent;` |
| 霓虹发光 | 底部导航激活态、主按钮 hover | `box-shadow: 0 0 16px rgba(99,102,241,.55)` |
| 玻璃拟态 | 首页卡片、弹层 | 见 3 节 CSS |
| 高亮描边 | 图表折线/饼图 | 线条用 `--neon-cyan`，配同色 glow |
| 数字滚动动效 | 金额统计 | 进入页面时数字递增动画（V1 可选） |

**界面用色建议**：

- 首页：深色背景 + 玻璃卡片，顶部「本月支出」用渐变大字，净资产用白字。
- 底部导航：未激活 `--text-muted`，激活态用主渐变填充图标 + 霓虹发光。
- 账单列表：支出金额 `--expense`（红），收入金额 `--income`（绿）。
- 预算进度条：正常用主渐变，接近超支 `--warning`，超支 `--expense` 并闪烁提示。

## 7. 可访问性与规则

1. 深色主题正文对比度 ≥ 4.5:1（WCAG AA）；`--text-secondary` 仅用于辅助信息。
2. 收支不单靠颜色区分，金额始终带 `+`/`-`。
3. 图表色板相邻颜色在深色底上保持足够色相差，避免色弱用户混淆。
4. 渐变色块上的文字统一用白色 + 适当字重，不叠加低对比文字。
